## Brand & Style

This design system establishes an ultra-refined, high-density operational platform tailored for enterprise IT teams, systems engineers, and tier 1â€“3 service desks. 

The aesthetic is anchored in Modern Corporate Pragmatism, drawing the analytical clarity of Linear, the structural rigor of Jira Service Management, and the approachability of modern productivity workspaces. It balances strict visual rhythm with micro-level contrast to reduce cognitive strain during high-stress triage and incident management.

Key attributes:
- **Tone:** Authoritative, calm under pressure, rigorously structured, efficient.
- **Visual Weight:** Light, neutral framing with sharp, semantic focal points for priority states, SLAs, and assignment queues.
- **Hierarchy:** Data-first presentation prioritizing rapid visual scanning, tabular legibility, and effortless keyboard navigation.

## Colors

The palette leverages a crisp, cool-slate architecture to allow data-dense dashboards to breathe, using strategic saturated accents strictly for actions, states, and urgencies.

### Core Roles
- **Primary Canvas & Chrome (`#0F172A`, `#1E293B`):** Governs structural headers, persistent enterprise navigation bars, active drawer accents, and high-emphasis display type.
- **Accent & Interaction (`#2563EB`, `#1D4ED8`):** Applied exclusively to primary interactive triggers, active breadcrumb trails, row focus rings, and selected workspace states.
- **Neutral & Structural Framing (`#F8FAFC`, `#F1F5F9`, `#E2E8F0`):** `#F8FAFC` anchors the master view background; `#FFFFFF` provides isolated card clarity; `#E2E8F0` delineates grid dividers, table cells, and input borders.

### Semantic Status Tokens
Status tokens must always pair their dominant stroke/text token with a tinted background container for effortless peripheral recognition:
- **Open:** `#2563EB` text on `#EFF6FF` container.
- **Assigned:** `#7C3AED` text on `#F5F3FF` container.
- **In Progress:** `#D97706` text on `#FFFBEB` container.
- **Resolved / Stable:** `#059669` text on `#ECFDF5` container.
- **Closed / Inactive:** `#64748B` text on `#F1F5F9` container.
- **Critical / P1 / SLA Breach:** `#DC2626` text on `#FEF2F2` container.

## Typography

The dual-type hierarchy cleanly separates macro-level workspace orientation from micro-level incident telemetry:
- **Headlines (Plus Jakarta Sans):** Introduces a modern, calibrated geometry for section titles, modal headers, and analytical metrics.
- **Body & Labels (Inter):** Serves as the high-legibility workhorse for dense ticket descriptions, table data cells, audit trails, and metadata chips.

All ticket references (e.g., `INC-8921`), code traces, and SLA countdowns should inherit monospaced tabular numerals (`font-variant-numeric: tabular-nums`) to prevent alignment jitter during real-time status refreshes.

## Layout & Spacing

The layout operates on a fluid, edge-to-edge multi-panel paradigm configured for high information throughput:

### Structural Grid & Shell
- **Navigation Shell:** A 64px collapsed (or 240px expanded) fixed-left navigation rail paired with a 48px global utility header.
- **Main Canvas:** A responsive multi-column layout. In queue and triage views, an optional collapsible secondary pane (360pxâ€“420px width) docks to the right for rapid ticket inspection without navigating away from the stream.
- **Desktop (â‰¥1280px):** 12-column dynamic grid, `gutter-desktop` (1.5rem), `margin-desktop` (2rem).
- **Tablet (768px - 1279px):** Inspector pane shifts to a floating slide-over drawer; gutters contract to `1rem`.
- **Mobile (<768px):** Primary content reflows into a single-column stack. Tables convert to stacked summary cards; margins reduce to `1rem`.

Compact element spacing rhythm maintains high density: use `space-xs` and `space-sm` for internal component padding to maximize above-the-fold telemetry.

## Elevation & Depth

Visual separation relies primarily on sharp, structural 1px borders (`#E2E8F0`) reinforced by whisper-quiet ambient shadows. Heavy dropshadows are explicitly omitted to preserve a clean, professional utility feel.

- **Level 0 (Flat / Canvas):** Applied to the base canvas (`#F8FAFC`). No shadow, no outline.
- **Level 1 (Card / Table Surface):** Crisp `#FFFFFF` surfaces bounded by a 1px border of `#E2E8F0`, paired with an ambient shadow: `box-shadow: 0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
- **Level 2 (Dropdowns / Flyout Menus / Popovers):** Elevated surface with a 1px border of `#CBD5E1` and ambient elevation: `box-shadow: 0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Modals / Slide-Over Inspection Drawers):** High-priority focus overlays with a subtle border tint and deep diffused falloff: `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.06)`. Accompanied by a 24% dark slate backdrop overlay (`rgba(15, 23, 42, 0.35)`).

## Shapes

The design uses a refined, compact radius profile (Soft / `roundedness: 1`) to preserve an engineered, tool-like precision:
- **Base Components (Inputs, Table Rows, Buttons, Badges):** 4px border radius (`0.25rem`).
- **Cards, Filter Bars, and Containers (`rounded-lg`):** 8px border radius (`0.5rem`).
- **Modal Dialogs & Slide Panels (`rounded-xl`):** 12px border radius (`0.75rem`).
- **Pill Exception:** SLA countdown badges and user status indicator dots alone may use complete circular rounding (`9999px`) to create clear differentiation against rectilinear tabular data.

## Components

### Buttons
- **Primary:** Background `#2563EB`, text `#FFFFFF`, hover `#1D4ED8`, focus ring `2px #2563EB` with `2px` white offset. Height 32px (compact) or 36px (standard).
- **Secondary / Outline:** Background `#FFFFFF`, border 1px solid `#E2E8F0`, text `#334155`, hover background `#F8FAFC`.
- **Destructive:** Background `#DC2626`, text `#FFFFFF`, hover `#B91C1C`.

### Status Badges & Chips
- Padding: 2px 6px; typography: `label-sm` uppercase.
- Built strictly using semantic status tokens (e.g., `#FEF2F2` background with `#DC2626` text and border 1px solid `rgba(220, 38, 38, 0.2)` for P1 incidents).
